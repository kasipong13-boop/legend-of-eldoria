LEGEND OF ELDORIA - Chronicles of the Dragon Kingdom
Prototype 0.1  (เวอร์ชันทดลองเล่น)
=====================================================

เวอร์ชันนี้มีอะไรบ้าง
---------------------
- หมู่บ้าน Greenvale มุมมอง isometric เดินสำรวจได้
- ตัวละคร Novice (Lv 1, HP 50)
- มอนสเตอร์ Poring เดินเพ่นพ่านอยู่ในหมู่บ้าน
- ระบบต่อสู้แบบผลัดตา ใช้การ์ด (การ์ดเริ่มต้น 5 ใบ)
- รางวัลหลังชนะ: EXP, Gold, ไอเท็มดรอป (Poring Jelly), เลเวลอัป

ยังไม่มีใน 0.1 (ตั้งใจเว้นไว้ก่อน)
-------------------------------------
อาชีพอื่น, โซนอื่นนอกจาก Greenvale, มอนสเตอร์ Wolf และ Orc, ร้านค้า, ระบบเซฟ
ทุกอย่างจะเริ่มทำใน Prototype 0.2 หลังจากที่คุณทดลองเล่น 0.1 แล้วเท่านั้น


ในโฟลเดอร์มีอะไรบ้าง
---------------------
eldoria/
  index.html            <- ไฟล์ที่ต้องเปิดเพื่อเล่นเกม
  README_TH.txt         <- ไฟล์นี้
  css/
    style.css           <- หน้าตาของเมนู, HUD, หน้าต่อสู้
  js/
    data.js             <- ข้อมูลเกม: การ์ด, มอนสเตอร์, ตัวเลขกติกา (แก้ตัวเลขที่นี่)
    battle.js           <- กติกาการต่อสู้ (ไม่ยุ่งกับหน้าจอ ย้ายไป GDevelop ได้ง่าย)
    battle-ui.js        <- หน้าจอต่อสู้
    world.js            <- แผนที่ isometric, การเดิน, Poring
    main.js             <- เชื่อมทุกหน้าเข้าด้วยกัน, HUD, รางวัล
  assets/
    icon.svg            <- ไอคอนเกม (หน้าไตเติล)
    apple-touch-icon.png <- ไอคอนตอนเพิ่มเกมไว้บนหน้าจอหลักของ iPhone

หมายเหตุ: ตัวละคร, Poring, ต้นไม้, บ้าน วาดด้วยโค้ดทั้งหมด จึงไม่มีไฟล์ภาพตัวละคร
เกมนี้ไม่ใช้อินเทอร์เน็ตและไม่ต้องติดตั้งอะไรเพิ่ม


วิธีเปิดเกมบนคอมพิวเตอร์ (ง่ายที่สุด)
--------------------------------------
1. ดาวน์โหลดไฟล์ eldoria-prototype-0.1.zip
2. แตกไฟล์ ZIP ก่อน
   - Windows: คลิกขวาที่ไฟล์ ZIP แล้วเลือก "Extract All..." (แตกไฟล์ทั้งหมด)
   - Mac: ดับเบิลคลิกที่ไฟล์ ZIP
   ห้ามเปิดจากข้างใน ZIP โดยตรง เพราะเกมจะหาไฟล์อื่นไม่เจอ
3. เปิดโฟลเดอร์ eldoria ที่แตกออกมา
4. ดับเบิลคลิกไฟล์ index.html (จะเปิดด้วย Chrome, Edge, Firefox หรือ Safari)
5. กดปุ่ม "Begin the journey"

ถ้าดับเบิลคลิกแล้วเปิดด้วยโปรแกรมอื่น: คลิกขวาที่ index.html > Open with > เลือกเบราว์เซอร์


วิธีเล่น
--------
เดินสำรวจ
  - แตะ/คลิกที่พื้นเพื่อเดินไปตรงนั้น
  - หรือใช้ปุ่มลูกศรบนหน้าจอ (มือถือ) / ปุ่มลูกศร หรือ W A S D (คอมพิวเตอร์)
  - ปุ่มลูกศรเดินตามทิศบนหน้าจอ: ขึ้น = ขึ้นบนจอ, ซ้าย = ไปซ้ายบนจอ
  - ต้นไม้ บ้าน และน้ำ เดินผ่านไม่ได้
  - เดินไปชน Poring (ตัวสีชมพู) เพื่อเริ่มต่อสู้

การต่อสู้
  - HP ผู้เล่น 50, พลังงาน (Energy) 3 ต่อเทิร์น, จั่วการ์ด 5 ใบต่อเทิร์น
  - แตะการ์ดเพื่อใช้ทันที (เลขวงกลมสีฟ้ามุมการ์ด = พลังงานที่ใช้)
  - ป้าย "Next: ..." เหนือศัตรูบอกว่าเทิร์นหน้า Poring จะโจมตีเท่าไร
  - กด "End turn" เพื่อจบเทิร์น ศัตรูจะโจมตี
  - Block (โล่) ช่วยกันความเสียหายของเทิร์นนั้น และหายไปเมื่อเริ่มเทิร์นใหม่
  - Poring HP 20

การ์ดเริ่มต้น (สำรับ 10 ใบ)
  Strike x4   1 พลังงาน  ทำความเสียหาย 6
  Guard  x3   1 พลังงาน  ได้ Block 5
  Bash   x1   2 พลังงาน  ทำความเสียหาย 8 และได้ Block 4
  Fire Bolt x1 2 พลังงาน ทำความเสียหาย 12
  Heal   x1   1 พลังงาน  ฟื้น HP 8

หลังการต่อสู้
  - ชนะ: ได้ EXP 12, Gold 5-10, มีโอกาส 60% ได้ Poring Jelly
  - EXP ครบ 20 จะขึ้น Lv 2 (HP สูงสุด +5) ครบ 40 ขึ้น Lv 3 ต่อไปเรื่อยๆ
  - แพ้: ตื่นขึ้นมาที่หมู่บ้าน ไม่เสียอะไร
  - กฎของ 0.1: เมื่อกลับมาหมู่บ้าน HP จะฟื้นเต็มเสมอ
  - ยังไม่มีระบบเซฟ ถ้ารีเฟรชหน้าเว็บ ข้อมูลจะเริ่มใหม่


วิธีทดลองเล่นบน iPhone
-----------------------
อย่าพยายามส่งไฟล์ ZIP เข้า iPhone แล้วเปิด index.html จากแอป Files เพราะ iOS มักเปิดเกมแบบนี้ไม่ได้
ให้ใช้วิธีใดวิธีหนึ่งด้านล่าง

วิธีที่ 1 (ง่ายที่สุด): เปิดลิงก์เกมออนไลน์
  1. เปิดลิงก์เกม Prototype 0.1 ที่ได้รับในแชท ด้วย Safari บน iPhone
  2. เล่นได้ทันที ไม่ต้องติดตั้งอะไร
  3. (เลือกทำ) ให้เล่นเต็มจอเหมือนแอป: กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) >
     "Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม) > Add
     จากนั้นเปิดจากไอคอน Eldoria บนหน้าจอโฮม

วิธีที่ 2: ใช้คอมพิวเตอร์เป็นเซิร์ฟเวอร์ชั่วคราว (iPhone และคอมพิวเตอร์ต้องใช้ Wi-Fi เดียวกัน)
  1. แตกไฟล์ ZIP บนคอมพิวเตอร์ (ดูขั้นตอนด้านบน)
  2. เปิด Terminal (Mac) หรือ Command Prompt (Windows) แล้วเข้าไปในโฟลเดอร์ eldoria
       cd ที่อยู่ของโฟลเดอร์/eldoria
  3. สั่งรันเซิร์ฟเวอร์ (ต้องติดตั้ง Python ไว้):
       Mac:      python3 -m http.server 8000
       Windows:  py -m http.server 8000
  4. หา IP ของคอมพิวเตอร์ (Mac: ตั้งค่า > Wi-Fi > รายละเอียด / Windows: พิมพ์ ipconfig
     แล้วดูค่า IPv4) เช่น 192.168.1.20
  5. บน iPhone เปิด Safari แล้วพิมพ์ http://192.168.1.20:8000  (เปลี่ยนเลขเป็น IP ของคุณ)
  6. เลิกเล่นแล้วกด Ctrl+C ที่ Terminal เพื่อหยุดเซิร์ฟเวอร์

วิธีที่ 3: อัปโหลดโฟลเดอร์ขึ้นเว็บฟรี
  - เว็บอย่าง Netlify Drop (app.netlify.com/drop) ให้ลากโฟลเดอร์ eldoria ไปวาง
    แล้วจะได้ลิงก์ไว้เปิดบน iPhone
  - ระวัง: ลิงก์ที่ได้เป็นลิงก์สาธารณะ ใครมีลิงก์ก็เปิดเล่นได้


ปัญหาที่พบบ่อย
---------------
- หน้าจอว่าง/ปุ่มไม่ทำงาน: ตรวจว่าแตกไฟล์ ZIP แล้ว และเปิด index.html จากโฟลเดอร์ eldoria
  ที่ยังมีโฟลเดอร์ css, js, assets อยู่ข้างๆ
- iPhone: หน้าจอเลื่อนหรือซูมเอง: ลองเพิ่มเกมไว้หน้าจอโฮม (วิธีที่ 1 ข้อ 3)
- ไม่มีเสียง: ถูกต้อง เวอร์ชัน 0.1 ยังไม่มีเสียง
- เกมง่ายไป/ยากไป: บอกได้เลย จะปรับตัวเลขใน js/data.js
